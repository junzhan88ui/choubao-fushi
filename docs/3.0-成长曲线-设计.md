## 3. 计算层（新 `utils/growth.js`）

| 函数 | 职责 |
|---|---|
| `ageDays(birthday, dateStr)` | 生理日龄；`monthAt = days / 30.4375` |
| `lmsAt(table, sex, month)` | 月龄线性插值取 L/M/S（0–60 月逐月表） |
| `zScore(x, L, M, S)` | `L≠0: ((x/M)^L − 1)/(L·S)`；`L=0: ln(x/M)/S` |
| `percentileOf(z)` | 正态近似（Abramowitz–Stegun 有理逼近，误差 < 0.1%，纯自写不引库） |
| `bandOf(p)` | P 值 → 6 带（见下），返回 `{ key, label, range }` |
| `pointsFor(records, sex, metric)` | 记录 → `[{ date, ageDays, x, p }]`，缺 sex/超 60 月的点单独标记不混入 |
| `METRICS` | `weight / length / head` 三指标的单位、精度、合法区间、表引用 |

**区间口径（决策②）** —— 六带 + 中性命名，**不给评价词**：

| key | 区间 | 标签（照抄，不许加形容词） |
|---|---|---|
| lt3 | < P3 | `P3 以下` |
| p3p10 | P3–P10 | `P3–P10` |
| p10p50 | P10–P50 | `P10–P50` |
| p50p90 | P50–P90 | `P50–P90` |
| p90p97 | P90–P97 | `P90–P97` |
| gt97 | ≥ P97 | `P97 以上` |

配一句**恒定说明**（区间卡与免责声明各出现一次）：

> 百分位只表示在同龄同性别儿童中的位置，**不是健康评价**；有疑问请咨询医生。

## 4. WHO 数据表（新 `data/who-growth.js`）

- 来源：WHO Child Growth Standards 2006（0–5 岁），公开 LMS 参数。
- 三张表 × 两性别：**体重/年龄、身长/年龄、头围/年龄**，各 0–60 月逐月 L/M/S。
- 纯数字数组，估 10–20KB，主包可承受；无网络。
- ⚠️ **转录即责任**：录入时从官方原表抄 3–5 个中位数锚点一并写进 `_validate §6x`
  （如「男 6 月龄体重中位 = 官方值」），此后断言现算对照 —— 表抄错一次，钉一次。
